# キャラセレの操作説明画像4・5

両方使用する。data/demos/キャラセレ/script.ltonの技19「スクリプト16」が画像4（382×33）を、技20「スクリプト17」が画像5（380×31）を表示する。stage.loadは両方をレイヤーとして起動する。

画像4は最初30フレーム透明で保持し、(141,444)にalpha=23/32で表示する。SG 19,4は表示I命令へ戻り、以後その位置・透明度で表示し続ける。
画像5は最初32フレーム透明で保持し、(142,445)に不透明で表示する。SG 20,4も表示I命令へ戻り、以後表示し続ける。

画像4の方が幅・高さが2px大きく、画像5を1px内側に重ねる配置。両画像を確認すると4には5にない暗い輪郭画素がある。共通の操作説明を縁付きの背面・文字の前面として重ねる構成と判断できる。別モード用の切り替え画像ではない。スクリプトの静的確認によるもので、コードや素材の変更はしていない。
