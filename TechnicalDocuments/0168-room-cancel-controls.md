# ロビーのB/Dによる状態取り消し

ロビー内のB/Dは `READY → 着席（READY解除） → 未着席` と一段ずつ戻す。未着席では何もせず、ルーム退出には使わない。Esc / Backによる既存の離席・退出操作は維持する。ルーム以外の画面でも従来どおり戻る操作として扱う。

`src/roommenu.lh` のキャンセル入力で、READY中なら現在の席のREADYを解除し、着席中なら既存の離席処理を使う。画面下部の日本語・英語ガイドにも操作を記載する。

`tools/test-online.ps1` の模擬EOSテストで、BとDそれぞれのREADY解除、離席、未着席から退出しないこと、およびEsc / Backの従来動作を確認する。
