# システムのオブジェクトは "parent" のときだけ親基準

2026-10-12。試合前演出で、画面左上に加算合成のスプライト（システム画像 217〜223、231、232）が出ていた（ユーザー指摘、動画 0:06・0:12 付近）。
本来は画面中央付近に出る。

## 原因

`Fighter.spawn` はシステム（ラウンド・HUD）の O を、フラグによらず画面の (x, y) に置いていた（9bff667 の初期実装の簡略化）。
システム技はルートが画面原点で起動するので、ルートから生むものは問題にならない。オブジェクトが生むものだけがずれる。

- 「ｖｓ」#122 の `O 123, -4, 17, "out parent"` → (-4, 17)＝画面左上（画像 231、232）
- 「スクリプト18」#108 の `O 118, 24, ..., "parent"`（きら2、画像 213・217〜223）も同様

## 判定

データから、システムでは "parent" が位置の基準も決めていると判断:

- "parent" 付き（#108→#118、#122→#123、「一」「百」→#141）: オフセットはどれも小さく負値を含む → 親からの相対
- フラグなし: 「ｖｓ」は自分の複製を (300, 340) に置く（ｖｓ自身は (300, 320)）。相対なら (600, 660) で画面外 → 画面座標の絶対
- 位置付きで起動するシステム技（ヒット数・タイマー・ストック・勝ちマーク）は O を持たないので影響しない

## 変更

- `src/fighter.lh` `spawn`: picXY、または（システム かつ "parent" なし）なら画面の (x, y)。それ以外は生成元から（x は向きで反転）。
  画面座標系かどうか（`onScreen`）は従来どおり。
