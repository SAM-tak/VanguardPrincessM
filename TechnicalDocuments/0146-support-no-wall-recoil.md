# サポートの攻撃では画面端の押し戻しを返さない

2026-10-13。画面端で相手が下がれないとき、相手のやられ／ガード中に壁で止められた移動量を攻撃側に返して押し戻す（`Fighter.confineMotion` の `cornerPush`）。
これがサポートの攻撃のヒット・ガードでもプレイヤー本体に返っていた。原作ではそうならないと見られる（ユーザー指摘）ため、本体の攻撃でのみ返す。

## 変更（`src/fighter.lh`）

- `Fighter.fromSupport()`: 本体の管理番号5（`slots[5]`）がサポート。そのサポート自身と、生成元（`parent`）をたどってサポートに行き着くオブジェクト（サポートの飛び道具など）を真とする
- `recoilReturns`: そのやられ／ガードで押し戻しを返すか。`struck`（ヒット・ガード）と RP（投げ等のやられ移行）で、攻撃側が `fromSupport` なら偽、そうでなければ真にする
- `confineMotion` は `recoilReturns` が真のときだけ `cornerPush` を返す
- 本体の飛び道具（本体が生成したオブジェクト）は従来どおり返す

## 検証

- `tests/combat-flow.lh` の corner recoil: `recoilReturns` が偽のやられでは押し戻しが無いこと、`fromSupport` の判定（サポートとその子は真、本体と本体の子は偽）、
  サポートの `struck` で `recoilReturns` が偽、本体の `struck` で真になることを追加。combat regressions・support-flow・turn-result PASS
- 実機でサポートの攻撃を画面端で当てたときの見た目は未確認
