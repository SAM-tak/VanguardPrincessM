# アカウント表示名をプレイヤー名の初期値にする

2026-10-15。

Epicログイン成功後、EOS UserInfoで自分の表示名を問い合わせ、Connect認証完了時に `Client.displayName()` から取得できるようにした。Basic Profile権限を使い、取得失敗でも認証は継続する。Device IDでは空文字を返す。Steamの表示名取得は未対応で、ゲーム側にもSteamログイン画面はまだない。

ロビーの名前入力欄は保存済みの `settings.playerName` を優先する。未設定または空欄ならEpic表示名を初期値に使い、取得できなければ `Player` とする。従来の16文字制限に合わせて切り詰め、入力欄から自由に変更できる。

旧版が既定値 `Player` を保存してしまい、Epic表示名より優先する不具合を修正した。由来の印がない既存の `Player` は未設定とみなす。ユーザーが入力欄を編集して作成・参加を確定した場合だけ、名前と `playerNameSource = "custom"` を保存する。自動取得した表示名や取得失敗時の `Player` は独自名として保存しない。今後明示的に `Player` と入力した場合は保持する。ローカルの旧設定にも由来のない `Player` が存在したことを確認した。

EOS拡張の模擬SDKテストで通常・永続ログインの表示名取得、取得失敗時のログイン継続を確認。ゲームのオンライン試験では初期値への反映と保存済み独自名の優先を、ソースと配布用VMで確認する。実Epicアカウントでの表示名取得は別途実機確認が必要。
