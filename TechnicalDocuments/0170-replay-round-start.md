# 途中ラウンドからのリプレイ再生

リプレイ一覧では常に最初から再生する。再生中の上で次ラウンドへ、下で現在ラウンドの先頭（開始前演出中なら前ラウンドの先頭）へ移動する。判定は経過フレーム数ではなく `flow.phase` の `start / call / ready` を使う。戦闘開始後はKO・勝利・終了演出中も現在ラウンドの先頭へ戻る。先頭・最終ラウンドを越えて循環せず、キーリピートでも連続移動しない。一時停止中も操作可能。

新しい記録は第2・第3ラウンドなどから直接再開し、前ラウンドの入力・シミュレーションを実行しない。旧version 1/2は開始データがないため、未訪問ラウンドへの直接移動は行わず、従来どおり最初から再生する。

## 開始状態

キャラの技コルーチンは保存しない。`startRound()` の通常初期化で立ち状態・開始技・オブジェクト・HUDを作り直す。ただし既存のラウンド開始処理は入力バッファや一部のスカラー値を持ち越すため、ゲージ・勝利数・乱数だけでなく、それらの値も保存する。前ラウンドの残存オブジェクトや技は復元せず、既存の初期化で破棄する。

`src/roundstart.lh` は、ラウンド遷移中に `startRound()` を呼ぶ直前の値をJSONへ記録する:

- 両者のスカラー値、入力履歴、変数（初期化で消える値も含む）。配列の順序はこのモジュール内で固定し、ペイロードのversionで識別する。
- システム変数、取得ラウンド数などのフロー値、乱数状態、フレーム番号、ビュー位置。
- ステージ各レイヤーの数値・変数とデータスクリプトの実行位置。

ステージ演出はラウンドをまたいで続く。`src/script.lh` が画像待ち・空ループ待ち・ブロック数上限待ちの位置を `Fighter` に保持し、復元時は新しいコルーチンをその位置から作る。画像待ちの残り時間と、待ちから抜ける際の1フレームも元の動作に合わせる。VMのコルーチンスタックや同一オブジェクトへの参照はファイルへ保存しない。

復元後は通常の `startRound()` とラウンド遷移tickの後半（カーテン・勝利マーク・ステージ・HUD・キャラの初回ステップ）を実行し、ブロック先頭の乱数・ゲージ・勝利数と照合する。現在の原作ステージには生成オブジェクトがない。将来そのようなステージが追加された場合は状態を省略して復元することを避け、開始データを作らず、そのラウンドを途中再生候補にしない。

## 形式と互換性

新規保存はversion 3。[0169](0169-replay-round-blocks.md)の24バイトのラウンドヘッダに続けて、開始データのバイト数（uint32）、JSONのバイト列、入力列を置く。第1ラウンドは従来の試合設定から初期化できるので開始データは空。開始データは最大1MiBとし、読込時に残りファイル長も検査する。文字単位のsubstringは使わず、`std.binary`でバイト単位に取り出す。

ネット対戦のロールバックで境界を再シミュレーションした場合は開始データも作り直す。巻き戻し用 `Saved` は、次の境界に紐付ける開始データも保持する。ラウンド境界も巻き戻し用スナップショットとして保持し、訪問済みの境界はそれを復元する。未訪問ラウンドは開始データから構築する。ステージを構築し直した後に古いスナップショットへ戻る際は、ステージ・ラウンド・HUDの参照も元へ戻す。

`vp.main.playReplay(name, number)` が開始ラウンド指定の入口。非整数・未記録ラウンド・開始データのないラウンドは拒否する。シーンの読み込み中、リプレイ再生中、ネット対戦中も開始しない。

`main.lh` のモジュールスロット上限を避けるため、リプレイ実行中の変数は `vp.replay.Runtime` にまとめた。

## 検証

- `replay-format`: version 3の開始データ（UTF-8を含む）の往復、version 1/2の読み込み、不正ブロックの拒否、ロールバック時の境界差し替え。
- `replay-round-start`: CPU対戦を記録して通し再生の各フレームを保存。前ラウンドの入力を故意に壊し、第2・第3ラウンドからの再生がキャラ・ステージ状態と最終結果まで一致することを確認。
- `replay-round-navigation`: 最初からの再生、再生中の上下移動、開始・ラウンドコール・READY演出、READY最終フレームと戦闘開始直後、終了演出、先頭・最終ラウンド、キーリピート、一時停止中の操作、移動後の状態と最終結果を確認。
- `stage-round-start`: 全7ステージをそれぞれ5時点で保存し、その後100フレームずつ、移動・変数・画像・スクリプト位置・乱数の一致を確認。
- `replay-controls` / `snapshot-replay`: 既存の早送り・巻き戻し・スナップショット復元。
- `tools/test-replay-round-start.ps1`: スクリプト・定義をコンパイルして配布用VMで上下移動テストを実行。`-Test replay-round-start` では独立した途中再生のテストを実行する。テスト用EOSモックを使い、メディアは既存のassetsを共有する。

観戦の通信・配信・ライブ入力への追従はこの変更には含まない。
