# サポートの表示順・欄外ルーレット

ユーザー指定（2026-10-14）。通常の左右移動を表示順のかなえ104 → シエラ102 → えこ101 → ジュリエット103に合わせる。かなえから左、ジュリエットから右は欄外のルーレット。入った側にかかわらず、ルーレット中の左入力でジュリエット103、右入力でかなえ104の通常選択へ戻る。

Select.SideのsupportSlotは-1〜4で、0〜3が通常枠、-1/4が欄外。rouletteIndex/frameで現在の候補を持つ。ルーレットはえこ101 → シエラ102 → ジュリエット103 → かなえ104 → ヒルダ105を8シミュレーションフレーム刻みで巡回する。ヒルダは通常の4枠に加えない。決定入力のあるフレームでは候補を進めず、直前の表示を確定する。

## 原作データとの関係

各キャラのportrait.ltonの#25/#26に通常4サポートのV142/V143代入、欄外の巡回、105代入がある。巡回の後半はI命令の保持8フレーム。原作スクリプトそのものはヒルダの前にRnd(100,40)の分岐を持ち、一部には1Pのみモードを除外する条件もある。今回の指定「一定の並びで次々変わり、このルーレットにのみヒルダを含む」に合わせ、ポートでは5人の固定巡回にする。

サポートの絵・名前・アイコンには既存のキャラセレdemoを使用する。元の1x1制御用portraitはCOM入力や旧ルーレット処理が並行して候補を変えないよう、showSupportで対応する代入から実行した後controlParkedで制御用のstepだけを止める。子オブジェクトは通常通りアニメーションする。ルーレット中は通常矢印を破棄し、候補が変わるたび通常の移動音が連打されないようにする。

syncSupportDemoが候補に対応する既存V分岐へ表示用レイヤーを進める。元のフェードの待ち時間で絵だけ遅れて選択値と違う候補を見せないため。必要なレイヤーはaliveも復帰させる。ヒルダは4枠のアイコン列にいないので、通常枠の選択アイコンは表示しない。欄外に「?」、下端に日英のルーレット表示を追加。元画像は変更しない。

確定時はfinishSupportで元のV141/V134の確認分岐の飛び先を実行し、既存の決定演出と音を維持する。待機中も候補変数が変わらないのでヒルダを105として対戦に渡せる。試合後のrestoreSupportも105をえこに置き換えず復元する。

## キャンセルと決定音

B(2)とD(8)はキャンセル専用。mainでは決定せず、supportではキャラ・パレット・仮のサポートを保持してmainへ戻る。readyは取り消さない。決定はA/C/E/F。メイン決定時にも現在のシステムカーソルからsound(7)を呼ぶ（元の確定カーソル#86/#87がS7で鳴らす音）。support決定時の既存S7も維持する。
