# 試合のスナップショットとリプレイの早送り・巻き戻し

2026-10-15。ロールバック型ネットコードの前段として、試合状態のスナップショット（取得と復元）を作り、
リプレイ再生の早送り・巻き戻しに使った（ユーザー指定）。巻き戻しは 0 フレーム目からやり直すのではなく、
直前のスナップショットを復元してそこから再シミュレートする。

## 技コルーチンは L^ の save() / load() で戻す

キャラ・システム・ステージ・HUD・飛び道具はすべて `Fighter` で、技はデータ駆動のインタプリタ
`script.run` を技ごとのコルーチンとして動かしている（`fighter.skill`。中断点は `run` のループと
`show` → `hold` の表示待ち）。このコルーチンの実行状態を、L^ に入った `co.save()`（`costate^`）／
`co.load(s)`（02 の 15.16）で保存・復元する。

- 戻るのはフレームだけ（ローカル・中断位置・`await^` の先）。ヒープは戻らないので、Fighter のフィールドは別にコピーする
- `load()` は保存したそのコルーチンにしか使えない → スナップショットは複製ではなく**同じオブジェクトへの書き戻し**。
  スナップショットが Fighter と技コルーチンへの参照を持ち続け、復元で `fighter.skill` をそのコルーチンに戻して `load()` する。
  保存後に生まれた Fighter（飛び道具・火花）は参照されなくなるだけ、保存後に消えたものは復活する
- `tests/costate-probe.lh`: ゆいの立ち・前進を表示待ちの途中で保存し、復元後 120 フレームの画像列が一致（乱数は同じシードで揃える）

## スナップショットの中身（`src/snapshot.lh`、`main.lh` の `snapshot` / `restore`）

- **Fighter**: me / foe から objects・slots・parent・owner・enemy・hitEventTarget をたどって到達できるもの全部と、
  round（layers・portraits・marks・combos）・hud（layers と個別の参照）・stage の layers。
  各 Fighter の状態は `copyStateTo`（`fighter.lh`、定義から機械的に列挙した 110 フィールド）で入れ物の Fighter にコピーする。
  保存（実物→入れ物）と復元（入れ物→実物）で同じ関数を使い、可変テーブル（判定 Box・変数・入力履歴・objects・slots・残像）は
  毎回コピーするので、スナップショットは何度でも復元できる。画像・音・技定義・コマンドなど、技のパッケージが与えるものはコピーしない
- **Round / Hud / Stage**: 各 `copyStateTo`、stage は layers の列
- **乱数**: `src/rng.lh` を xorshift32 の L^ 実装に変更（状態は数値1つ）。LÖVE の `RandomGenerator` は lhat-love で
  状態の取得・設定を公開していない
- **その他**: shake の2軸、システム変数（`fighter.lh` のモジュール変数）、CPU の脳（参照と `copyStateTo`）、
  main.lh のカメラ・ラウンド時間・フレーム数・`wasTiming`・`replayFrame` など
- 音は戻さない。巻き戻し時はキャラの音を止める（ステージの BGM はそのまま）

`def^` のインスタンスには `clone^`（素のテーブル専用）が使えないので、フィールドは明示的に列挙している。
`def^` の中で自分の型の `new` を呼べない（「read before its let^ has run」）ため、残像のコピーは定義の外の関数。

### 費用

試合中（1000 フレーム目）で取得 7.3ms、復元 4.6ms。リプレイ（1秒に1回）には足りるが、
ロールバックで毎フレーム取るには重い（1フレーム 10ms）。入力履歴（Fighter ごとに 1024 要素×3）の複製などを
差分化するのが次の課題。

## リプレイの早送り・巻き戻し

- 再生中、100 フレームごと（そのフレームの最初、入力を流す前）にスナップショットを取る
- → 押しっぱなしで 4 倍速（1 フレームに 4 tick）
- ← で、今から 30 フレーム以上前の直近のスナップショットへ戻る。押しっぱなしで 0.25 秒ごとに続けて戻る
- 画面下に `REPLAY` の帯（状態・経過/全体時間・操作）。ESC で中断、Start で一時停止（従来どおり）

## 検証

- `tests/snapshot-replay.lh`（`-Test snapshot-replay`）: CPU 同士の VS を記録して再生し、1000 フレーム目で取得、
  1400 フレーム目の状態（位置・体力・ゲージ・技・画像・飛び道具・乱数・カメラ）を記録して復元、を2回。
  2回とも 1400 フレーム目が一致し、試合の最後も記録どおり
- `tests/replay-controls.lh`（`-Test replay-controls`）: → 押しっぱなしで 20 フレームに 154 フレーム進み、← でスナップショットへ戻り、
  試合の最後も記録どおり
