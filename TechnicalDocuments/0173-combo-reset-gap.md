# コンボ表示数のリセット漏れ調査

2026-10-16。ゆいの立ちCで、前のコンボ数が次の攻撃にも継続するとの報告を調査。
原因を確認し、本体スクリプト終了時に表示数もリセットする修正を実施。

## 確認した不具合

表示用の被弾数 `Fighter.combo` は `main.lh` の `stepFighters` で、受け手の技番号が立ち・歩き・しゃがみ・ジャンプ等の列挙対象である場合に0へ戻る。
ところが `control` は終了した被弾技からのコマンド入力を、通常立ちへの移行より先に処理する。
硬直終了直後に攻撃を開始すると、列挙対象の技を経由せず、被弾数が残ったままになる。
次の攻撃を受けると `strike` が残った値へ加算する。

一方、ダメージ補正用の `damageHits` は `Fighter.finishDamageChain` が本体スクリプトの終了時に0へ戻す。
このため「補正は新しいコンボの1発目、表示だけ前回の続き」という不一致が発生する。
被弾側の共有処理が原因であり、攻撃データの個別設定に限定されない。

## 実データでの確認

調査用コピーに `control`／`stepFighters` を呼ぶ入口とヒット直前のログを追加し、描画・音声なしのエンジンで固定フレーム実行した。
元の技・判定・被弾スクリプトを使用。調査用入口は `build/combo-audit/`（Git管理対象外）。

- ゆいの立ちCはコマンド「強斬り」から #224「　真・強斬り」へ入る。ヒット後の #225 への遷移や、#224 の残像オブジェクトが過去の表示数を復元しているわけではない。
- ゆい・えり・はるかを相手に、立ちCを200フレーム間隔で当てる試験では、通常立ちに戻った後の各ヒットは毎回 `combo=0` から始まった。
- 立ちCの被弾 #88 が終了したフレームに受け手へC入力を与えると、攻撃 #224 を実行中でも `receiving=false, combo=1` が残った。
- その状態への次の攻撃として、ゆいの立ちA #213、立ちB #228、立ちC #224 のすべてで、ヒット直前の `combo=1` とヒット後の `damageHits=1` を確認。3技×受け手3人の9組で表示数が2へ進んだ。
- ダウン後も同様。過去の表示数5を持つ受け手を実際の #164 ダウンスクリプトから再開し、終了直後にC入力を与えると、次の立ちCで表示数が6、補正数が1になった。受け手3人で確認。この試験では初期の被弾数・ダウン状態を直接設定しており、5ヒットに至るまでの攻撃列は再現していない。

## 報告との対応と修正方針

「硬直・ダウンから復帰して行動できた後も表示数が残る」経路は再現できた。
通常立ち #1 を実際に経由した後まで残る現象は未再現。ユーザーからも、CPU等の動く相手でのみ確認し、動かない練習相手では再現していないとの回答があり、今回の経路と一致する。
他キャラの全技を個別実行したものでもないが、同じ受け手側のリセット処理を使うため、ゆいの立ちCに限らず発生し得る。

## 修正と検証

`Fighter.finishDamageChain` で本体スクリプトが終了した際、`damageHits` とともに `combo` も0へ戻す。
補正数が0でも表示数は残り得るため、従来の `damageHits > 0` 条件は外す。オブジェクト・システム個体は対象外。
通常立ちを経由しない復帰直後のコマンド入力にも対応し、SG／DS／サブルーチン復帰で処理が続く間はリセットしない。

- `tests/combo-correction.lh`: 表示数と補正数の終了・継続境界、補正数0での表示数リセット、オブジェクト・システム個体の除外を確認。`tools/test-async.ps1 -Test combo-correction` から実行可能にした。
- `tests/combat-flow.lh`: ゆい・えり・はるかの #88 被弾と #164 ダウン終了直後にC入力を与え、通常立ちなしで攻撃できても表示数が0であることを確認。空中の #163 受け身可能落下では表示数・補正数を維持することも確認。
- 同テストの既存の多段技、足払いから超必殺技への追撃、コンボ色、ガード・着地・壁反応の検証も実施。
- 調査用のダウン後再被弾試験でも、修正前の表示6に対し、修正後は新しい1ヒット目になった（受け手3人）。
- 気絶ではカウントを継続する。`tests/combat-flow.lh` で #177 の気絶吹き飛びから着地・#181・#179／#180 の立ち気絶まで実行し、過去の5ヒットを維持して追撃が6ヒット目になることを確認。追撃せず気絶が解けた場合は0へ戻る。ゆい・えり・はるかの3人で成功し、戦闘回帰テスト全体も通過。本体の追加変更は不要だった。
